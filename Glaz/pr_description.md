## Обзор

Реализована система определения объектов на экране с использованием грубой подписи (zoomed signature) и динамического масштабирования лупы для точной вписки объекта в большой круг.

## Основные изменения

### Архитектура
- **Рефакторинг кода**: разделение на модули app.py, capture.py, image_processor.py, loupe.py, utils.py
- **Модульная структура**: каждый модуль отвечает за свою область функциональности

### Система определения объектов
- Грубое определение (step1): объекты определяются только на этапе грубой подписи
- Удален step2: полное разрешение больше не используется для определения
- База данных объектов: сохранение и загрузка подписей из ~/.glaz/objects.json
- Fuzzy matching: поиск похожих объектов с допуском в 2 сегмента
- Динамическая подгонка: автоматическое масштабирование лупы для вписки объекта в большой круг

### Лупа с умной геометрией
- Красные/синие сегменты: синий - нет пиков, красный - обнаружены пики
- Геометрия лупы: перекрестие (20 сегментов), квадраты 12x12 и 24x24, ромб, описывающие круги
- Скриншоты с геометрией: сохранение кадров лупы с отрисованной геометрией и цветными сегментами

### Детекция объектов
- Поиск по линиям: вертикаль, горизонталь, диагонали
- Автоцентрирование: курсор автоматически перемещается в центр объекта
- Удержание курсора: предотвращение случайных сдвигов во время определения

### UI улучшения
- Две таблицы: грубые объекты и объекты полного разрешения (legacy)
- Превью скриншотов: отображение сохраненных кадров лупы
- Логирование: цветные сообщения (зеленый для знакомых объектов)
- Полноэкранный режим: автозапуск на мониторе 2 (если подключен)

## Технические детали

### Алгоритм определения объекта

1. При наведении на объект: курсор центрируется, рассчитывается оптимальный размер лупы
2. Грубое определение (step1): динамическая подгонка масштаба, снятие подписи, поиск в БД
3. Скриншоты: рендер кадра лупы с геометрией, сохранение и отображение

## Файлы изменений

- app.py (+840 строк): главное приложение, UI, логика определения
- loupe.py (+700 строк): контроллер луп, рендер геометрии
- image_processor.py (+280 строк): обработка изображений, детекция пиков и объектов
- utils.py (+186 строк): системные утилиты, работа с БД
- capture.py (+117 строк): захват экрана
- main.py (рефакторинг): точка входа
